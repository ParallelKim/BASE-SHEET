# 스튜디오에서 MIDI 검수하기

이 문서는 **이미 나온 MIDI를 사람이 어떻게 보는지**다. 출판 탭으로 채점 진리(`BarSpec`)를 잠그는 절차는 [chart-verification.md](chart-verification.md).

품질 기준은 **MIDI가 스템처럼 들리는 것**이다. 탭 점수 1.0이 목표는 아니다. 두 픽스처 스템은 킥·다른 저음이 섞일 수 있고, 소스 분리는 하지 않는다.

## 화면에 보이는 것

| 무엇 | 뜻 |
|---|---|
| 위 그림 (크롭) | 출판 그 마디. 보표가 비어 있으면 베이스가 쉬는 마디다. |
| `기보 N마디 · 타셋` | 구간 이름. **MIDI가 비어서가 아니다.** 있지 1–12마디는 출판 탭이 쉼표라 `tacet`이다. |
| 피아노롤 | 스템에서 검출한 음. 타셋 구간에도 음이 있을 수 있다 (믹스 잔여). |
| 성능 `.mid` | 스템 시간축. 스템과 같은지 들을 때 쓴다. |
| 양자화 `.quant.mid` | 박자에 붙인 것. 악보·TAB 정렬용이다. |

있지 타셋(1–12)은 채점하지 않는다. 피아노롤에 F#3·D3가 보여도 탭을 고치지 않는다.

## 검수 순서

1. 곡을 고른다. 있지는 「탭 있는 마디로」를 눌러 **13마디 벌스**로 간다. 빈 1마디에서 멈추지 않는다.
2. 크롭 TAB(줄·프렛)과 피아노롤 피치가 같은지 본다. 이전/다음 마디로 한 칸씩 간다.
3. 헤드폰으로 비교 WAV를 듣는다. **왼쪽=스템, 오른쪽=MIDI.** 같으면 그 구간은 통과다.
4. 탭과 MIDI가 달라도, 스템이 탭이 아니라 필·잔여를 치면 스템을 이긴다. 진리 피치를 깎지 않는다.
5. 전곡을 한 점수로 섞어 보지 않는다. 벌스·코러스·간주는 따로 본다.

로컬에서 마디별 텍스트 리포트:

```bash
python scripts/report_bar_scores.py
# out/listen/ijji_bars.txt  antifreeze_bars.txt
# out/listen/*.compare.wav
```

## 올리지 않은 곡

출판 크롭이 없으면 피아노롤·미리듣기만 본다. 비교 WAV가 있으면 그걸 기준으로 검수한다.
