# 스튜디오에서 MIDI 검수하기

이 문서는 **이미 나온 MIDI를 사람이 어떻게 보는지**다. 출판 탭으로 채점 진리(`BarSpec`)를 잠그는 절차는 [chart-verification.md](chart-verification.md).

품질 기준은 **MIDI가 스템처럼 들리는 것**이다. 탭 점수 1.0이 목표는 아니다. 두 픽스처 스템은 킥·다른 저음이 섞일 수 있고, 소스 분리는 하지 않는다.

## MIDI와 악보의 관계

| 화면 | 범위 | 뜻 |
|---|---|---|
| 위 마디 줄 | **연주 순서로 이어진 출판 마디** | 재생하면 재생 위치에 맞춰 부드럽게 스크롤. 노란 테두리 = 지금. 칸을 누르면 그 마디로. |
| 피아노롤 | **전곡 MIDI** | 가로 = 시간. 누르면 그 시간으로. 노란 세로선·띠 = 위 가운데 마디와 같은 시간. |

한 장만 보면 라인이 안 읽힌다. 그래서 크롭을 `PLAY` 순서로 붙여 보여 준다. Antifreeze처럼 반복이 있으면 출판 번호가 다시 낮아질 수 있다(예: …24 다음에 9).

연결: `재생 시간` → (BPM·t0) → `연주 마디` → `PLAY` → `출판 마디` → `mNNN.png`.

| 라벨 | 뜻 |
|---|---|
| `타셋 (출판 쉼표)` | 그 출판 마디의 베이스가 쉼표. MIDI가 비어서가 아니다. |
| 성능 `.mid` | 스템 시간축. 스템과 같은지 들을 때. |
| 양자화 `.quant.mid` | 박자에 붙인 것. 악보 정렬용. |

있지 타셋(1–12)은 채점하지 않는다. 그 구간에 피아노롤 음이 있어도 킥·잔여일 수 있다.

곡을 고르면 `review_from`부터 본다. 있지는 13마디 벌스, Antifreeze는 1마디. 피아노롤을 누르면 그 시간으로 간다.

재생 버튼은 비교·미리듣기 WAV가 있으면 그 소리를 쓰고, 롤·마디 줄이 `currentTime`과 같다. WAV가 없으면(정적 호스팅) 비프.

## 검수 순서

1. 곡을 고른다. 있지는 바로 **13마디 벌스**다.
2. 위 줄에서 가운데 칸과 좌우 몇 마디를 같이 보고, 아래 노란 띠 안 음과 TAB이 같은지 본다. 피아노롤 가로를 눌러 시간을 옮긴다.
3. 헤드폰으로 비교 WAV를 듣는다. **왼쪽=스템, 오른쪽=MIDI.** 재생이 WAV를 쓰면 화면 재생 위치와 같은 축이다.
4. 탭과 MIDI가 달라도, 스템이 탭이 아니라 필·잔여를 치면 스템을 이긴다. 진리 피치를 깎지 않는다.
5. 전곡을 한 점수로 섞어 보지 않는다. 벌스·코러스·간주는 따로 본다.

```bash
python scripts/report_bar_scores.py
# out/listen/ijji_bars.txt  antifreeze_bars.txt
# out/listen/*.compare.wav
```

## 올리지 않은 곡

출판 크롭이 없으면 피아노롤·미리듣기만 본다. 비교 WAV가 있으면 그걸 기준으로 검수한다.
